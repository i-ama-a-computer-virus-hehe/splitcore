# Core Dominion v4.21

Added start menu, Core names, visible name labels, leaderboard, scalable-world foundation, and a 12-player WebSocket server.

Run multiplayer:
1. Install Node.js.
2. In this folder run `npm install ws`.
3. Run `node server.js`.
4. Open `http://localhost:8080` in up to 12 browser tabs/devices.

The server connection/state synchronization is a foundation for the next multiplayer pass; gameplay authority and remote-player rendering still need expansion.
